The original adult.data, adult.test, and adult.names files are included without modification. The teaching code parses '?' as missing, strips whitespace, and normalizes the test target's trailing period. These parsing transformations do not alter the source files. Train/validation splitting and feature selection in the lesson are educational choices, not UCI's official benchmark protocol.

This historical census dataset is used for learning data preparation. Its labels, sampling, sensitive attributes and historical biases need scrutiny; the examples are not a recommendation to make consequential decisions about people. Dropping sensitive columns alone does not guarantee fairness. The app and the bundled examples make no production performance or fairness claim.

`workflow.py` is the Chapter 4 preparation example. `evaluation_workflow.py` is the Chapter 5 nested-selection/evaluation example; both read only these original local files. The Chapter 5 code and report explicitly identify cross-chapter test-source reuse, so its external result is not fresh confirmatory evidence. Cluster intervals concern fixed predictions and raw-profile clusters, not guaranteed independent persons or the complete training/search procedure.

`python_workflow.py` is the Chapter 6 import-safe Python engineering example. It reads only `adult.data` in validated chunks, computes descriptive audit summaries, verifies a bounded inspection merge, and optionally writes a JSON report. Source row positions are not person IDs. Full-source audit statistics must not be reused as training-fitted validation/test features. Numeric array payload is reported separately from total process memory; category counters grow with vocabulary size.

`math_workflow.py` is the Chapter 7 executable mathematics experiment. It uses only `adult.data`, with `hours_per_week` as the regression target and four declared numeric features. Both the outcome and income are excluded from the profile grouping key. The fixed training-only scaling/ridge objective is checked by finite differences, augmented least squares and deterministic descent; duplicated columns illustrate rank deficiency. This source has already been explored in the curriculum. The reported validation diagnostics are not fresh confirmatory evidence, the canonical UCI benchmark, causal effects or a deployment claim.

`statistics_workflow.py` is the Chapter 8 import-safe inference audit. It verifies the original `adult.data` SHA-256, computes unweighted row income proportion, Wilson and explicit Beta–Bernoulli working intervals, a declared Some-college minus HS-grad hours/week contrast, and profile-cluster percentile bootstrap intervals. Wilson and Welch formulas are checked against SciPy. The grouping key excludes both outcomes (`income`, `hours_per_week`); groups are proxies, not verified person IDs. Unequal-size clusters use a resampled ratio of totals to retain the row-weighted estimand. The report records versions, seed42, resamples and model assumptions. Row methods assume independent observations; bootstrap assumes independent exchangeable profile clusters. `fnlwgt` is unused. This reused historical source provides no fresh confirmatory, causal education-effect or current-population claim. No external test is read, no model is trained, and no network is needed during execution.

`tree_workflow.py` is the Chapter 9 import-safe Decision Trees experiment. It verifies original `adult.data`, uses a fixed five-numeric-feature income classifier, group-safe development split and training-only three-fold grouped selection over eight declared configurations. It reports AP/accuracy/Brier, a prior baseline, MDI and an example decision path. A separate fixed age/education tree produces the training-derived cost-complexity pruning snapshots; a fixed hours/week regressor is another explicitly scoped experiment. The grouping key excludes both income/hours outcomes; profile groups are proxies, not verified independent persons. `fnlwgt` is unused. This reused historical source supplies development diagnostics, not fresh confirmation, a canonical benchmark, causal importance or a deployment claim. No adult.test access or network calls occur.

`tree_split_lab.json` is a derived excerpt of the first 24 original source rows (1-based source positions, age and binary income label). `tree_pruning_lab.json` contains fitted training-path snapshots (alpha/leaves/depth/weighted leaf Gini risk/train and development-validation accuracy), with source hash, task scope and split counts. Derived by the Chapter 9 teaching workflow; original data files remain unchanged. Both retain the UCI Adult attribution above under CC BY 4.0. Run `python assets/datasets/adult/tree_workflow.py --write-labs` to regenerate them with pinned dependencies. The app bundles these assets and computes split arithmetic in Dart; it does not execute Python or retrain pruning stages at runtime.

`ensemble_workflow.py` is the Chapter 10 import-safe development audit. It verifies original `adult.data`, uses five fixed numeric features, a raw-profile grouped split and training-only three-fold comparison of four declared RandomForest/HistGradientBoosting candidates. Internal random early stopping is explicitly disabled. Fixed bagging/AdaBoost and two-feature squared-loss regression runs are separate teaching experiments. No external test/network is used. CPU threads are bounded. Both outcomes are excluded from grouping; profiles are proxies, `fnlwgt` is unused and row-OOB may include related peers in training. Reused historical diagnostics are not fresh confirmation, causal importance or deployment evidence. External XGBoost/LightGBM/CatBoost packages are discussed conceptually, not installed/benchmarked.

`ensemble_bagging_lab.json` stores actual training source positions/labels and 24 fixed bootstrap members' probabilities/in-bag membership. `ensemble_boosting_lab.json` stores actual validation source positions/hours, baseline and16round staged predictions/tree outputs/RMSE for three independently fitted rates. The source hash/task scope are included. Derived teaching assets retain UCI Adult attribution under CC BY 4.0; original files are unchanged. Regenerate with `python assets/datasets/adult/ensemble_workflow.py --write-labs`. The app performs Dart arithmetic on bundled assets; it does not train Python models at runtime.

`classical_workflow.py` is the Chapter11 import-safe SVM/kNN/Naive Bayes audit. It verifies original `adult.data`, uses the fixed outer profile-group split, and selects6,000 outer-training groups with label-independent seed42 for a bounded6,013-row training budget. Six declared LinearSVC/kNN/GaussianNB configurations use three inner grouped folds; transforms fit inside training folds. AP uses SVM decision scores without invented probabilities. Other probability APIs may report Brier. Convergence warnings fail the run. The budget differs from earlier chapters, so metrics are not a controlled cross-chapter ranking. No external test/network, causal/current-population or fresh-confirmatory claim; proxy profiles, both outcomes excluded from grouping, fnlwgt unused.

`classical_svm_lab.json` contains separate two-feature balanced linear SVC fits on1,024 training rows, subset-only scaler, actual plotted rows/queries, coefficients/support flags/counts and decision references. `classical_knn_lab.json` contains64 real training rows, held-out queries and full-budget-training feature scales. `classical_nb_lab.json` contains fixed two-feature Gaussian parameters/epsilon/priors, actual queries and independent library log-posterior references. Derived teaching assets retain UCI Adult attribution above under CC BY4.0; original files unchanged. Run `python assets/datasets/adult/classical_workflow.py --write-labs` to regenerate. The app performs Dart geometry/distance/log-density arithmetic on these assets; it does not execute Python. Equal-distance cutoff ties follow explicit pool order, not an assumed universal library ordering.


`unsupervised_workflow.py` is the Chapter 12 import-safe clustering/PCA audit. It verifies the original source hash, uses only age/education_num/hours_per_week and never uses income for fitting, scoring, colors or hyperparameter choice. The existing income/hours-excluding profile key produces a fixed seed42 group-safe 26,050/6,511 development split; 6,000 randomly budgeted training groups contain 6,013 rows. Training-only StandardScaler feeds k=2..5 diagnostics (one fixed 1,200-row silhouette sample), a declared k=3 seed sensitivity check, and 3D PCA/held-out reconstruction. There is no automatic best-k or semantic/causal/fairness claim.

The three `unsupervised_*_lab.json` files are derived from 96 actual budget-training age/hours rows, with original 1-based source positions, under the same CC BY 4.0 attribution. They contain no income labels or invented observations. The k-means asset stores bounded fixed-start Lloyd snapshots with smallest-ID ties/keep-empty policy. The density asset stores independent Python/sklearn reference results for a separate runtime Dart core-connectivity implementation; ambiguous borders have an explicit ordering policy. The PCA asset fits separately on these displayed raw/standardized coordinates, with deterministic component signs. This 2D lab scope differs from the main 3D experiment. `--write-labs` explicitly reproduces these assets; ordinary analysis only prints/optionally saves a report. Source files are unchanged, `adult.test` is not read, `fnlwgt` is unused, groups are proxies, and repeated use of this historical source is exploratory rather than fresh confirmatory validation.
