## Evidence and audit labs

portfolio_lab.json contains original frozen decision/audit records, six derived quote-inspection records, four provenance cards, 12 recomputed summaries, 16 explicit metadata-audit fixtures, and16 distinct role-specific prompts. Nine original JSON/JSONL/notice files are hashed in report.dependencies. The original files are not changed; no new training or reserved Wine/Bike/Spambase outcomes are scored.

all/first5/last5 are ordered descriptive slices. They are not randomized samples, demographic groups, fairness estimates, or locked test sets. Classification uses fixed operating thresholds and meaningful undefined denominators; recommendation computes macro precision/recall/NDCG over nonempty eligible-gold users; RAG reports provenance/format/emission counts and unknown truth accuracy. Cross-project metrics do not form a comparable leaderboard. Flutter recomputes summary arithmetic from bundled frozen records; this is not a new model-training/inference benchmark.

Audit faults none/source_mismatch/license_missing/production_claim modify only a copied metadata contract. Mismatching field names are shown; source assets remain unchanged. This is an explicit app metadata/claim fixture. CLI verification checks actual bytes and semantic crosslinks separately. Matching trusted hashes establishes consistency, not authenticity, scientific validity, rights compliance, or personal ownership.

## Mock drafts

Four roles: ML Engineer, Data Scientist, Recommendation Engineer, LLM/RAG Engineer. Four rounds each: project, coding, statistics, systems. All16 prompts are distinct, authored practice; no employer questions or hiring guarantees. Each includes focus, follow-up and six manual review fields: contract/source/baseline/validation/failure/limits.

The learning app stores draft text and checks in existing local SQLite settings under ch40:mock:<role>:<round>. No schema reset, API, authentication, timer or automatic semantic grading. Save is explicit. Switching before save discards current unsaved edits; Reload restores saved content; Clear current edits does not change saved data until Save. Role/round loads use revision checks so a stale asynchronous response cannot overwrite another round. Save captures its target key and content. Each draft is bounded; malformed saved schema reports an error without automatic overwrite. Learner progress, notes, bookmarks, quiz answers, themes and coding drafts remain separate. Evidence export does not contain private mock drafts.

## Reproduction

Python3.12 plus tool/requirements-python-qa.txt suffices for the verifier; workflow itself uses the standard library. No GPU required. Run python tool/check_chapter_40_code.py. Import/default CLI preserves source/reference bytes; --write-lab explicitly regenerates only derived portfolio_lab.json. Paths are based on __file__, supporting external working directories.

Run python assets/datasets/final_capstone/portfolio_workflow.py --artifact-dir build/chapter-40-artifacts , then --verify-dir build/chapter-40-artifacts . Six payloads: portfolio_lab.json,evidence_contract.json,mock_prompts.json,PORTFOLIO_TEMPLATE.md,ATTRIBUTION.txt,MOVIELENS_SOURCE.txt; checksums.json is the index. Verifier checks exact file set, payload hashes, scope flags, actual dependency bytes, regenerated semantic summaries/prompts/template, and original notice bytes. Corruption and semantic tampering with refreshed checksums are rejected. Original repository dependencies are required; this bundle does not duplicate all prior raw sources. Template explicitly requires the learner's actual contribution and next validation; exporting it does not establish achievement.
