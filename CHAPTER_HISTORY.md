# ML Path

A fully offline Flutter learning app for Android and iOS. **Includes Chapters 1–40: ML Fundamentals; Linear Regression in Depth (including variants); Classification Fundamentals; Data Preparation & Feature Engineering; Model Evaluation & Experiment Design; Python Engineering for ML; Linear Algebra, Calculus & Optimization; Probability, Statistics & Inference; Decision Trees; Ensembles & Boosting; SVM, kNN & Naive Bayes; Clustering & Dimensionality Reduction; Anomaly Detection & Time Series Foundations; Classical ML Capstone; PyTorch Tensors & Autograd; Neural Networks & Backpropagation; Reliable Deep Learning Training; CNNs, Computer Vision & Transfer Learning; Sequence Models; Attention & Transformers; Deep Learning Capstone; LLM Foundations; Embeddings & Semantic Retrieval; RAG Systems; Fine-tuning & Efficient Adaptation; LLM Evaluation, Reliability & Serving; Generative Models: VAE & GAN; Diffusion & Multimodal Systems; LLM/Generative AI Capstone; Recommendation Foundations; Matrix Factorization & Feature Interactions; Deep Recommendation & Ranking; Recommendation Evaluation & Feedback Loops; Recommender Capstone; ML Data Pipelines & Feature Systems; Serving, Monitoring & MLOps; Experimentation & Causal Reasoning; ML System Design Cases; Technical Interview Practice; and Final Capstone, Portfolio & Mock Interviews.** Lessons teach in Bangla with English technical terms. No login, backend, API keys, analytics, or runtime network requests. No chapters beyond Chapter 40 are included.

## Run

Requires Flutter 3.47.9 / Dart 3.13.7 or compatible newer SDK, plus Android SDK or macOS with Xcode for iOS.

```sh
flutter pub get
flutter run
```
